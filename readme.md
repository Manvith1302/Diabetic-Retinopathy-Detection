# Diabetic Retinopathy Detection

This project detects diabetic retinopathy severity using EfficientNetB0 and retinal fundus images.

Dataset:
APTOS 2019 Blindness Detection

Classes:
0 - No DR
1 - Mild DR
2 - Moderate DR
3 - Severe DR
4 - Proliferative DR

Model:
EfficientNetB0 + Transfer Learning + CLAHE
